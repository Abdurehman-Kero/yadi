# Contributing

- Read `docs/06-agent/AGENT_RULES.md` and `docs/04-engineering/` first.
- Work one milestone at a time; write the milestone docs before code; tests before implementation.
- Before finishing: `node scripts/run.mjs all` must pass.
- Never commit `.env` or real user data. Dev credentials in `docker-compose.yml` / `.env.example` are throwaway values for a local-only database.
- Commits are made by the project owner.
