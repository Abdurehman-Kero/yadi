# API Specification (draft)

Base path `/api/v1`. JSON. The OpenAPI document generated by FastAPI is the machine-readable source of truth; this file is the human summary. The web app reaches the API through a Next.js `/api/*` rewrite. Auth: session cookie (HttpOnly, SameSite=Lax) once real auth lands. Until then the dev identity: when `DEV_IDENTITY_ENABLED=true`, requests act as the seeded user, or the user named in the `X-Dev-User` header (used by tests); otherwise 401. All routes scoped to the authenticated user.

## Error format
```json
{ "error": { "code": "VALIDATION_FAILED", "message": "Human-readable", "details": [{"field":"dueAt","issue":"..."}], "requestId": "..." } }
```
Codes: `VALIDATION_FAILED` 400 · `UNAUTHENTICATED` 401 · `FORBIDDEN` 403 · `NOT_FOUND` 404 · `CONFLICT` 409 · `AMBIGUOUS_REFERENCE` 422 · `AI_UNAVAILABLE` 503 · `RATE_LIMITED` 429 · `INTERNAL` 500. Internal details are never returned.

## Endpoints (by milestone)
| Method & path | Purpose | M |
|---|---|---|
| GET `/health`, `/health/ready` | liveness, DB readiness | M01 |
| GET/POST `/tasks`, GET/PATCH/DELETE `/tasks/:id` | task CRUD (DELETE = cancel) | M02 |
| POST `/tasks/:id/start`, `/complete`, `/reopen` | lifecycle | M02 |
| GET `/tasks/:id/events` | history | M02 |
| POST `/assistant/extract` | text → `TaskDraft[]` + clarifications (no save) | M03 |
| GET `/schedule?from&to`, POST `/schedule/generate` | read/regenerate plan | M04 |
| PATCH `/schedule/blocks/:id` | manual edit; locks the block | M04 |
| GET/PUT `/tasks/:id/dependencies` | tasks this one waits for | M04 |
| GET `/reminders`, `/reminders/service-status`; POST `/reminders/:id/snooze`, `/cancel` | reminders | M05 |
| GET `/notifications`; POST `/notifications/:id/read`, `/read-all` | in-app notifications | M05 |
| POST `/push/subscriptions`, `/push/unsubscribe` | browser alerts | M05 |
| POST `/assistant/message` | conversational command → proposal; `/assistant/confirm` applies | M06 |
| GET/PUT `/preferences` | settings | M02+ |

Lists use cursor pagination (`?limit&cursor`). Mutations accept an `Idempotency-Key` header where retries are likely.
