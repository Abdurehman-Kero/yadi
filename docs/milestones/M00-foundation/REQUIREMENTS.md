# M00 Requirements

M00 produces documents, not features. It is complete when:
1. Product vision, requirements, personas, flows, UX principles exist.
2. SRS (Word), use cases, acceptance criteria, traceability exist and use unique IDs.
3. Architecture, data model, API, AI, scheduling, notification, security docs exist.
4. ADR-001..004 are Accepted by the owner; ADR-005 is decided or explicitly deferred with a date/milestone.
5. Roadmap, risks, open questions, success metrics exist.
6. Agent continuity files exist and reflect real state.
7. Plan Review Report delivered and owner feedback incorporated.
