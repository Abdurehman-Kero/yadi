# User Flows

## F1 Capture
Type "assignment due Friday, 2 hours on project, meeting tomorrow 10" → Yadi shows extracted items with editable fields and any questions ("Which Friday time?") → user confirms → tasks saved → schedule proposed → reminders created.
Failure: AI unavailable → manual form pre-filled with the user's text.

## F2 Plan the day
Dashboard shows today's blocks, next action, at-risk items → user accepts, edits (drag/lock), or regenerates → conflicts listed with options.

## F3 Conversational change
"Move project work to the afternoon" → Yadi resolves the task (asks if several match) → validates → applies → states what changed → undo available.

## F4 Reminder
Reminder fires (in-app / push) → user marks done, snoozes, or reschedules.

## F5 Complete / cancel
Mark complete from list, schedule, or chat; reminders cancelled automatically; history recorded.

## F6 Overload
Not everything fits → Yadi says so, shows what doesn't fit and options (move deadline, drop/defer lower priority task).

## F7 Settings
Set timezone, working hours, reminder defaults, notification permission.
